# 农场生产工作流

入口：收益规划页或侧栏的「生产工作流」，页面路径 `/planner/workflow/`。原来的收益排行仍保留。此工具在浏览器内计算和保存，不读取游戏存档。

## 开始安排

1. 在「计划资源与计算设置」填写起始日期、现金、土地和已有机器，可推演 1–112 天。
2. 从快捷入口选作物，添加「买种 → 种植 → 出售」；也可以分别添加库存、买入、种植、加工等节点。
3. 点击种植节点修改播种日期、格数和地块。默认只种一轮；勾选「收获后自动续种」后，逐轮续种。需要时另勾选「种子不足时，按缺口自动补买」。
4. 拖动输出端点到下一节点的输入端点。也可在「连线管理」使用下拉框连接，适合触屏和键盘操作。
5. 点击日历日期，查看当天每一次买种、播种、收获、投料、交付和到账。点击操作名称可定位对应节点。

补买和补种不是固定发生在月初：买入节点可安排任意一天；自动补买只购买当轮缺少的种子，并记录数量与支出。未勾选续种时，每一轮使用独立种植节点，日期和下游流程均可不同。多次结果作物收获后继续占地，不重复消耗种子。

「停止安排日期」限制新的播种或投料，不取消已开始的生长或加工。种植还要满足允许季节；没有核实的跨季转化、特殊多阶段收获和缺少生长数据的作物不自动推断。

## 框选与副本

拖动画布空白处框选节点；中键或右键拖动画布，滚轮缩放。支持复制、粘贴、删除、撤销、重做以及对应的 Ctrl/Cmd 快捷键。文字输入框内仍使用普通文字编辑快捷键。

副本使用新编号，只带入选区内部连线。只复制种植节点时不会自动连接旧的买种、加工或交付节点；复制完整生产链会保留链内连接。复制粘贴缓冲区属于当前页面，可跨「新建」操作使用；跨浏览器或长期备份使用导入导出。

## 供奉、交付和留货

新计划按照四季留货页的当前默认季节目录生成供奉、村长交付节点，逐组列出需求。已完成或不准备做的组可删除，重新计算和刷新不会将其补回。切换季节后，可以使用「补充所选日期所在季节的留货」主动添加，已有组不会重复生成。

自动生成的组没有推定截止日期，默认只保护库存。设置交付日期后，系统仅在指定日凑齐整组时交付；未凑齐会提示，货物继续保留，不悄悄改为晚交。自定义任务、供奉和日常消耗可以手动添加物品与数量。随机任务以玩家自己的进度为准。

节点只能使用已连接来源的库存。留货优先于加工和出售，多原料配方必须全部凑齐才会扣料。共享机器不足时排队，不能让同一台机器同时被两条流程重复使用。

## 初始状态与计算假设

- 已有种子、原料等使用「已有库存」，不重复计入购买支出。
- 种植或加工节点可设置「计划开始时已经在进行」及剩余天数；已有投入不再次扣款或扣料，仍然占用相应土地或机器。
- 每月 28 天，每年 112 天。统一每天操作一次，播种日加生长天数作为收获日；加工分钟数按 24 小时向上取整，最早次日领取。
- 出货到账默认延迟 1 天，可设置为 0–7 天。这是需要玩家核实的计算假设，尚未到账的货款不能用于购买。
- 机器默认每台同时加工 1 批；改良型号的装料数量不直接当作并行批数，可按游戏实测修改。
- 商店供应检查使用现有年份、季节记录。额外解锁条件会提示玩家确认。不能仅凭物品有买价就视为可以购买。
- 统一品质为整份计划的价格估算假设，不模拟混合品质继承、天气、肥料、体力或价格整数舍入。

现金净流入是推演范围内的到账收入减实际支出；待到账、库存、留货和在制品分别展示，不把未出售库存当作现金。当前机器资源按已有机器处理，机器购置及解锁过程不自动扩充资源。

## 保存与维护

计划自动保存在当前浏览器，导出 JSON 可做备份或迁移。导入检查版本、有限数值、节点和连线数量、重复编号及环路。上限为 200 个节点、500 条连线、同时 500 批加工。

主要代码：`src/domain/workflow/` 为纯计算域；`src/domain/workflowEditor.ts` 为计划创建、复制和导入；`src/components/workflow/` 为画布和日历；`src/data/workflowPayload.ts` 为静态数据。未来推荐器可以生成同一版本的计划格式，再通过同一个模拟器验证。

验证：`npm run verify` 运行内容检查、测试、类型检查和静态构建；`npm run check:build` 检查输出链接。
