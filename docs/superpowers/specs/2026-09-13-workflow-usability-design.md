# 工作流交互与田地选择

用户已授权直接实施。本轮跨越流程编辑、物品检索、交付进度及游戏地图数据，按独立可验证模块推进。

- 种植主数量显示同时占地；整季播种与收获放在明细。日程摘要显示当日支出、到账，累计钱包变化仍保留于展开详情。连线使用主题前景色。
- 节点输入/输出侧提供悬停新增入口，连线中点提供插入入口，统一菜单选择节点类型，提交一次完成新增与连线，可一次撤销。下游自动项重新推断，手动项保留。新增位置取当前可见画布区域，不主动移动视角。
- 只有清除选择后确实能唯一推断时才提供恢复物品自动选择；不能推断时保留原选择并解释原因。
- 交付详情逐项显示图标、截至所选日期已备数量、需求、全计划缺口、预计备齐日期。补前置优先连接现有来源；作物补种子和种植，唯一配方补加工及材料，其他来源明确生成需要玩家确认持有的库存节点，避免编造购买渠道或重复安排。
- 物品选择排除直接解锁的角色外观类别，增加类型筛选；作物不按计划季节截断，提供可选季节筛选。滚动增量加载全部匹配项，取消固定 80 项上限。
- 移除底部重复的待配置清单，控制日程详情滚动边界。
- 田地从本地游戏归档解析实际可耕网格，保留数据来源和校验；选择器支持框选、取消、全选和自动计数，将数量应用到播种规模，不启用全局土地资源约束。无法确认的地图字段不按猜测发布。
- 保留日粒度、自动数量与日期、手动机器台数及续种决策；不实现全局最优规划。

验证：域测试覆盖图变更、自动恢复、前置生成和进度；浏览器覆盖新增/插入、撤销、视角保持、筛选与增量加载、交付、框选。完成后构建独立 4335 预览并更新报告。
