## 编辑口径与限制

AppMedia 只用于确认主题范围、流程顺序与攻略要点；站点不复制来源段落或图片。游戏内名称、价格、配方、加工时间、季节和关系优先于网页数据。标题级要点保留日文小字以便核对；特殊作物采用不同的数据结构，无法可靠套用普通成长阈值时明确显示数据不足。

运行 `npm run content:check` 可重新验证覆盖集合；运行 `npm run verify` 可执行聚焦测试、类型检查、完整静态构建与 Pagefind 索引。
