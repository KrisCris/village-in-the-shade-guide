# 内容覆盖与限制

更新：2026-09-06。游戏快照：构建 `24969282`。参考目录：[AppMedia](https://appmedia.jp/honogurashi/)。

## 已有内容

结构化数据覆盖物品、种植记录、机械加工、制作与料理、鱼类、居民，以及已解析的商店、交付、解锁和家畜关系。界面提供列表、双向详情与收益规划。

原创指南包括四季留货、帮忙券 / 推进目标、生日送礼、外观获取、祠堂能力、收集地图、钓鱼准备、料理准备、夜间准备、特殊种植、狩猎和家畜。关键数值和条件以 `data/sources/game-*.json`、结构化快照及 `docs/data-evidence/` 的核对记录为依据。

## 尚未完整覆盖

- 参考目录有 116 个已映射主题。映射检查仅验证目录集合与目标链接，不证明每个主题都有完整、可执行的正文；旧主题页仍有标题级内容。
- 原创指南不是日文站点逐篇全译，也不声称覆盖全部剧情分支、随机任务或隐藏条件。
- 地图展示已解析点位，不代表所有物品在任何进度下都可取得。
- 生日、礼物偏好及部分食谱传授有原生证据；未核实的餐厅学习次数不能统一写成“吃 3 次”。
- 品质倍率下的小数金额仍是估算，游戏最终整数显示规则未完全核实。
- 排行依赖页面列出的生长、时长、种子供应等假设，不等于考虑了所有天气、技能、机器排队和玩家行动的最优解。

保留证据和不确定性；不要把“有一条价格记录”写成“商店可买”，也不要把某次随机交付写成永久固定需求。

`npm run content:check` 验证主题映射；`npm run verify` 执行前端测试、类型检查与生产构建。它们不能代替游戏内实证。
