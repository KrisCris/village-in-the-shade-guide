# 今日农务

**简体中文** | [English](daily-planner.en.md)

入口：顶部导航的“今日农务”，或收益规划页里的链接，路径 `/planner/today/`。选一个槽位存档（`save.001`–`save.005`），页面列出今天要做的事。存档只在浏览器里读取，不会上传，也不会被修改。

## 页面内容

- **换季提醒**：本季结束前来不及成熟的田间作物，以及最后一天不收就会枯萎的成熟作物。
- **现在可以收获**：成熟的作物、枯萎但仍可收获的作物（毛豆变成的黄豆），以及结果季里长成的果树。
- **今天的杂务**：耕地和田垄上还没浇水的作物、还没喂的动物、出货箱里等着结算的物品数、要清理的枯萎作物。
- **加工设备**：已经做好的产品、空着的设备、正在加工的产品和最早完成时间。
- **交付委托**：背包和收纳箱里的物品已经够交的项目，以及还差的材料。较高品质的物品也算在内。村长家的交付目录还没开放时只显示提示。
- **未来 7 天**：按每天都浇水计算，每天会有哪些作物成熟。
- **农田**：农田范围里已种下、已耕待种、要重新翻耕、长了杂草或树的格子数。

每一组作物都可以点“地图”，在农场地图上标出对应的格子。

午夜后的存档（00:00–06:59）还属于前一天。页面会提示离 07:00 换日还有几个小时。

## 农田范围

存档只记录耕过的格子，空着的耕地和田垄每晚约有一半会变回平地，所以存档本身说不清你有多少地。页面在浏览器里记住农田范围：

- 每次读取存档，所有耕地、田垄、水田和种着作物的格子会自动加入。
- 在地图上框选格子，可以手动加入或移出。只能选能耕作的地面，建筑、设施和地板下的格子会被跳过。
- 手动移出的格子以后不会再自动加入。
- 范围按存档里的玩家名分开保存（`localStorage` 键 `village-daily:farm-area:v1`）。浏览器禁止存储时，范围只在当前页面有效。

## 规则依据

以下规则用同一槽位连续五个存档核对：秋 28 日 07:00 和 00:00、冬 1 日 07:00 和 00:00、冬 2 日 07:00。

| 规则 | 存档里的证据 |
| --- | --- |
| 07:00 换日；浇水和喂食在换日时重置 | 冬 1 日浇过水的 381 格作物和喂过的 8 只动物，到冬 2 日 07:00 都变回没浇水、没喂。只有一株还没到结果季的桑树一直标着浇过水 |
| 浇过水的耕地和田垄上，作物每晚长 100 点 | 380 格全部 +100 |
| 栽培包和果树不浇水也每晚长 100 点 | 全部 +100，包括冬天户外的秋季栽培包 |
| 下一季不能生长的田间作物在换季时枯萎 | 秋 28 日预测的芋头 50 格、芝麻 2 格，和冬 1 日枯萎的格子完全一致 |
| 栽培包和果树换季不枯萎 | 同上 |
| 枯萎的作物留在地里，直到清理 | 秋 28 日早上地里还有 40 格夏季作物（黄瓜、蓝莓、玉米、毛豆）的枯株，当天被清掉 |
| 空着的耕地和田垄每晚约一半变回平地，无法预测 | 177 格耕地变回 89 格，188 格田垄变回 92 格；变与不变的格子数据相同；种着作物的格子不会变 |

另外几条来自游戏数据或站内已有资料：

- 成熟的毛豆换季后变成可收获的黄豆，是唯一在 `harvest_stages` 里有枯萎收获阶段的作物，不会被列进“最后一天不收就枯萎”。
- 果树只在 `perennial.bearing_seasons` 里的季节结果；温室限定的果树四季都列着。
- 交付接受要求品质及以上的物品，没有期限。目录在标志 12036 开启后开放。
- 水田不用浇水。

## 还没核实

- 没浇水的田间作物：存档里所有在长的田间作物都浇过水，没有对照。预测按每天浇水计算。
- 下雨是否自动浇水、肥料对生长的影响、温室格子：存档里没有对应情况。

## 代码位置

- `src/lib/saveDaily.ts`：从存档读出格子、设备、物品、委托和动物。
- `src/domain/dailyDigest.ts`：每日规则，不依赖存档，测试用合成数据。
- `src/lib/farmArea.ts`：农田范围的合并和存储。
- `src/components/daily/`：页面和农田地图（复用存档编辑器的 `MapCanvas`）。
- 用存档核对规则的测试在 `src/lib/saveDaily.test.ts`，需要解密的存档样本（见 `tests/gamesave/README.md`），没有样本时自动跳过。
