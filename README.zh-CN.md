# 静谧田园 Wiki

[English](README.md) | **中文** | [日本語](README.ja.md)

《Village in the Shade / ほの暮しの庭》（静谧田园）的非官方 Wiki 与攻略站，提供游戏资料查询、交互地图、农场规划和浏览器存档编辑器。

网站支持简体中文、繁體中文、日本語和 English。[访问网站](https://kriscris.github.io/village-in-the-shade-guide/)

数据直接从游戏文件提取，名称、说明和图标与游戏一致。项目基于这些游戏数据编写攻略，设计交互地图与规划工具。当前对应 Steam 构建 `25640656`，即 1.30 版本。

## 网站内容

- Wiki 资料库：查询作物、机械、加工、制作与料理配方、鱼类、角色和全部物品。各条目关联价格、来源、用途、商店、交付与解锁条件，支持分类浏览、筛选和表格排序。
- 玩法攻略：安排四季留货、播种与跨季种植，了解品质与品牌、料理、家畜、建筑、扩地和温室。也可查询生日与送礼、食谱传授、服装、祠堂能力、狩猎、帮忙券与主线推进，以及 1.30 的生日、播种机和卫浴设备。
- 钓鱼与采石查询：按季节、时段和钓点查看鱼类、上钩概率及交付留货。采石场可逐层查看掉落、平均产量、地图布局、特殊房间和首次到达奖励。
- 夜间探索攻略：查询怪异的出现条件、应对方法、交换与奖励，查看深夜妖怪的出没范围和伤害，以及通过咒物提高心与活力上限的方法。
- 交互收集地图：查找遗失图书、机械部件、幽灵老鼠、玉手箱、狐狸神社和交换地点。支持搜索、分类筛选、查看获取方法和勾选已收集，进度保存在浏览器中。
- 收益规划：比较种植与加工的日净收益、每颗种子净收益和当月收入。可调整季节、年份、种子来源与品质，并查看播种、收获和加工时间线。
- 生产工作流：在画布上连接购买、种植、续种、多级加工、留货、交付和出售，按天查看土地占用、机器排队、库存与收支。支持购物清单和方案导入导出。[生产工作流说明](docs/workflow-planner.md)
- 每日规划：在本地读取存档，生成交付、收获、加工、加造设备、采集材料、种植、饲养与补图鉴的待办清单。可查看成熟预报和换季提醒，在农场与村庄地图上定位任务，并保存农田范围。[每日规划说明](docs/daily-planner.md)
- 存档编辑器：编辑名字、金钱、日期、天气、玩家状态与外观、物品与容器、加工设备、家畜、好感、任务进度、图鉴、技能、配方和品牌。在浏览器中预览或撤销修改，再导出新存档。[存档编辑器说明](docs/save-editor.md)
- 农场与室内布局编辑：批量种植、修改地形、浇水和耕地，放置、移动或旋转建筑、设施与家具。支持季节与成熟预览、触屏操作和撤销，可通过 JSON 导入导出在存档之间复用布局。
- 搜索：按名称、拼音或首字母查找游戏条目，也可搜索攻略全文。
- 离线应用：安装到桌面或主屏幕，下载当前语言的页面、图片和地图后离线使用。页面设置中可以暂停或继续下载。
- 页面设置：切换昼夜与四季主题，开关飘落效果、调整物品品质和播放背景音乐。

## 本地运行

安装 Node.js 24 LTS 后，在仓库目录运行以下命令。

```sh
npm ci
npm run dev        # 生成数据并启动开发服务器，地址见终端输出
```

```sh
npm run build      # 生成静态站点和 Pagefind 搜索索引，输出到 dist/
npm run preview    # 预览生产构建
```

网站采用静态部署。Astro 在构建时生成页面，React 负责筛选、规划器和编辑器等交互，Pagefind 提供搜索。大列表和详情数据按需加载、分批渲染，性能测试请使用生产预览。

## 检查与测试

```sh
npm test               # Vitest
npm run check          # Astro 与 TypeScript
npm run content:check  # 主题映射
npm run i18n:check     # 翻译完整性
npm run verify         # 以上全部，加生产构建
npm run check:build    # 构建后检查站内链接
uv run pytest          # 提取器测试（需 Python 3.11+ 和 uv）
```

每个 pull request 都会在 GitHub Actions 上运行 `npm run verify`、链接检查和 pytest。合并到 `main` 后再次检查并部署到 GitHub Pages。

存档编辑器的回归测试使用作者的测试存档，CI 通过仓库密钥解密 `tests/fixtures/gamesave.tar.gz.enc` 后运行。测试存档的配置和更新方法见 [tests/gamesave/README.md](tests/gamesave/README.md)。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `src/pages/`、`src/components/`、`src/layouts/`、`src/styles/` | 页面、组件和样式 |
| `src/domain/` | 收益计算、工作流模拟和实体关系 |
| `src/data/`、`src/lib/` | 数据读取、存档读写和通用工具 |
| `src/i18n/` | 界面语言与翻译目录 |
| `data/generated/build-25640656/` | 当前游戏快照（1.30 版本），旧构建 `25311578`、`24969282` 留作对照 |
| `data/sources/` | 地图、规则、存档编辑器目录等专项数据 |
| `docs/` | 说明文档和数据核对记录 |
| `public/` | 图标、地图、场景、立绘等展示素材 |
| `src/honogurashi_extractor/`、`tools/` | 只读提取器和维护脚本 |
| `tests/` | 提取器测试和测试存档说明 |
