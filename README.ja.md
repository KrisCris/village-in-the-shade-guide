# ほの暮しの庭 Wiki

[English](README.md) | [中文](README.zh-CN.md) | **日本語**

『ほの暮しの庭』（Village in the Shade）の非公式 Wiki・攻略サイトです。ゲームデータの検索、操作できるマップ、農場の計画ツール、ブラウザーで使えるセーブデータエディターを備えています。

サイトは簡体字中国語、繁体字中国語、日本語、英語に対応しています。[サイトを見る](https://kriscris.github.io/village-in-the-shade-guide/ja/)

データはゲームファイルから直接抽出し、名称・説明・アイコンもゲーム内のものを使っています。攻略記事、操作できるマップ、計画ツールは、このゲームデータをもとに制作しています。現在のデータは Steam ビルド `25640656`、バージョン 1.30 に対応しています。

## サイトの機能

- Wiki データベース：作物、機械、加工、工作・料理のレシピ、魚、住人、全アイテムを調べられます。価格、入手方法、用途、店、納品、解放条件を関連項目からたどれます。カテゴリ別の閲覧、絞り込み、表の並べ替えにも対応しています。
- 攻略ガイド：季節ごとの取り置き、種まきと季節をまたぐ栽培、品質とブランド、料理、家畜、建物、農地拡張、温室を扱っています。誕生日と贈り物、レシピの伝授、服装、祠の能力、狩猟、お手伝い券とストーリーの進行、1.30 の誕生日・種まき機・水回り設備も確認できます。
- 釣り・石切場のデータ：季節、時間帯、釣り場ごとに魚のヒット確率や納品用の取り置きを確認できます。石切場は階層別のドロップ、平均入手数、マップの形、特殊部屋、初到達の報酬を調べられます。
- 夜の探索ガイド：怪異の出現条件、対処法、交換と報酬、深夜のお化けの出現範囲とダメージ、呪物で体力・元気の上限を上げる方法を確認できます。
- 収集マップ：紛失図書、機械の部品、幽霊ネズミ、玉手箱、狐の社、交換場所を探せます。マーカーの検索と絞り込み、入手方法の表示、収集済みのチェックに対応し、進捗をブラウザーに保存します。
- 収益プランナー：栽培と加工の1日あたりの純利益、種1個あたりの純利益、月間収入を比較できます。季節、年、種の入手元、品質を設定し、種まき・収穫・加工のタイムラインを確認できます。
- 生産ワークフロー：購入、栽培、植え直し、複数段階の加工、取り置き、納品、販売をキャンバス上でつなげます。日ごとの土地使用量、機械の待ち行列、在庫、収支を確認でき、買い物リストや計画のインポート・エクスポートも使えます。[生産ワークフローの説明（英語）](docs/workflow-planner.en.md)
- デイリープランナー：ローカルのセーブデータを読み込み、納品、収穫、加工、設備の追加、素材集め、種まき、飼育、図鑑埋めのチェックリストを作ります。収穫予測や季節の変わり目の注意点を確認し、農場・村のマップで作業場所を探せます。農地の範囲も保存できます。[デイリープランナーの説明（英語）](docs/daily-planner.en.md)
- セーブデータエディター：名前、お金、日付、天気、ステータスと見た目、アイテムと収納、加工設備、家畜、好感度、クエストの進行、図鑑、スキル、レシピ、ブランドを編集できます。ブラウザー内で変更を確認・取り消してから、新しいセーブファイルに書き出します。[セーブデータエディターの説明（英語）](docs/save-editor.en.md)
- 農場・室内のレイアウト編集：作物や地形をまとめて配置し、水やりや耕作、建物・設備・家具の配置、移動、回転ができます。季節や作物の成熟状態のプレビュー、タッチ操作、取り消しに対応し、JSON のインポート・エクスポートで別のセーブにレイアウトを移せます。
- 検索：名前、ピンイン、その頭文字でゲーム内の項目を検索でき、攻略文の全文検索も使えます。
- オフラインアプリ：デスクトップやホーム画面にインストールし、選択中の言語のページ、画像、マップをダウンロードしてオフラインで閲覧できます。ページ設定からダウンロードを一時停止・再開できます。
- ページ設定：昼夜モードと季節のテーマ、舞い落ちるエフェクト、アイテムの品質、BGM を設定できます。

## ローカルで動かす

Node.js 24 LTS をインストールし、リポジトリのディレクトリで次のコマンドを実行します。

```sh
npm ci
npm run dev        # データを生成して開発サーバーを起動。URL はターミナルに表示
```

```sh
npm run build      # 静的サイトと Pagefind の検索インデックスを dist/ に生成
npm run preview    # 本番ビルドをプレビュー
```

サイトは静的ホスティングで動作します。Astro がビルド時にページを生成し、React が絞り込みやプランナー、エディターの操作を処理します。検索には Pagefind を使っています。大きな一覧や詳細データは必要に応じて読み込み、分割して描画します。性能を確認するときは本番ビルドのプレビューを使ってください。

## チェックとテスト

```sh
npm test               # Vitest
npm run check          # Astro と TypeScript
npm run content:check  # トピックの対応関係
npm run i18n:check     # 翻訳の網羅性
npm run verify         # 上記のチェックと本番ビルド
npm run check:build    # ビルド後にサイト内リンクを確認
uv run pytest          # 抽出ツールのテスト（Python 3.11+ と uv が必要）
```

プルリクエストごとに GitHub Actions で `npm run verify`、リンクチェック、pytest を実行します。`main` へのマージ後に再度チェックし、GitHub Pages にデプロイします。

セーブデータエディターの回帰テストには、作者のテスト用セーブデータを使っています。CI はリポジトリのシークレットで `tests/fixtures/gamesave.tar.gz.enc` を復号してからテストを実行します。設定と更新の手順はテストデータの README にあります。[tests/gamesave/README.md（英語）](tests/gamesave/README.md)

## ディレクトリ構成

| パス | 内容 |
| --- | --- |
| `src/pages/`, `src/components/`, `src/layouts/`, `src/styles/` | ページ、コンポーネント、スタイル |
| `src/domain/` | 収益計算、ワークフローのシミュレーション、データ間の関連付け |
| `src/data/`, `src/lib/` | データへのアクセス、セーブデータの読み書き、共通ユーティリティー |
| `src/i18n/` | UI の言語設定と翻訳カタログ |
| `data/generated/build-25640656/` | 現在のゲームデータ（1.30）。旧ビルド `25311578`、`24969282` は比較用に保存 |
| `data/sources/` | マップ、ルール、セーブデータエディター用カタログなどの個別データ |
| `docs/` | 説明文書とデータの検証記録 |
| `public/` | アイコン、マップ、背景、立ち絵などの素材 |
| `src/honogurashi_extractor/`, `tools/` | 読み取り専用の抽出ツールとメンテナンススクリプト |
| `tests/` | 抽出ツールのテストとテスト用セーブデータの説明 |
